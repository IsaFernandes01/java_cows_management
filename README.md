# java_cows_management
This project was built to learn Java syntax, OOP principles, and core language concepts, marking my progress in Java development.

# Functionalities
It runs at CLI entirely, so nothing too complex here:
- creates vacas, pastos and manejos
- removes vacas, pastos and manejos (following a small business logic)
- list vacas, pastos and manejos (for devs, we're using IDs to make it simple)

# Tecnical Concepts
Praticed and learned Java principles:
- Reference Types (first contact)
- Composition
- Dependency Injection (in it's simpler implementation)
- ArrayLists and general types <>
- ArrayList manipulation
- Access Modifiers
- Non-Access Modifiers

# How to run?
By running Main.java, it connects everything else
